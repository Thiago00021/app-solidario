DoeMais

É um app solidário para doações de roupas, alimentos e móveis .

Tecnologias : React Native, Expo SDK 54, SQLite(expo-sqlite), ReactNavigation(Stack+tabs).


Desenvolvido por : Thiago Cardoso .

Observação : Esse aplicativo tem como finalidade consolidar o conhecimento adquirido em âmbido acadêmico e seu uso é para fins educacionais. Tive ajuda de amigos desenvolvedores fora do âmbito acadêmico e também utilizei inteligência artificial para me auxiliar .
